## THINGS I STRUGGLED WITH

- Stack: `seen.count()` on a stack → compile error. Only maps/sets have `.count()`
- Stack: pushed `s[0]` before loop → double processed first character
- Stack: `match[')'] = ')'` → value must be opposite bracket
- Stack of pairs: `pval.push.first(val)` → wrong. Use `pval.push({val, min})`
- Stack of pairs: `pval.top().second()` → `second` is field not function
- Stack of pairs: `pval.top.first()` → `top()` needs brackets, `first` does not
- `grep` needs dot: `grep -r "text" .`
- SSL errors on curl — use `-k` or `http://`
- `unordered_set` vs `unordered_map` confusion
- Forgot `return false` at end of Contains Duplicate
- Index typo: `values[nums[1]]` instead of `values[nums[i]]`
- LC #238: hardcoded `b` instead of `i`
- libcurl: missing `-lcurl` → linker error
- libcurl: use `http://` not `https://` for localhost
- libcurl: `curl_easy_reset()` needed between requests
- Deque: `win.back()` before `!win.empty()` → crash
- Deque: used `if` instead of `while` when kicking from back
- SQLite: `VALUE` instead of `VALUES`
- Cron: `* 12 * * *` ≠ midnight. Midnight = `0 0 * * *`
