## SQL — COVERED W6 D2

**SELECT + FROM + WHERE:** SELECT picks columns. FROM picks table. WHERE filters rows before anything else.

**INNER JOIN:** Only matched rows from both tables. Unmatched rows on either side are excluded.

**LEFT JOIN:** All rows from left table. Unmatched rows on right show as NULL. Put the important table after FROM.

**RIGHT JOIN:** All rows from right table. Unmatched rows on left show as NULL. Rare — most people swap tables and use LEFT JOIN instead.

**GROUP BY:** Collapses rows with same value into one group. Every non-aggregate column in SELECT must appear in GROUP BY. Aggregates: COUNT, SUM, AVG, MAX, MIN.

**HAVING:** Filters groups after grouping. WHERE filters rows before grouping. That is the only difference.

**Subquery:** SELECT inside SELECT. Inner query runs first. Use IN (SELECT ...) to check if a value exists in a list.

**Index:** `CREATE INDEX idx_name ON table(column)`. Speeds up lookups. Seq Scan = no index = slow. Index Scan = index used = fast.

**EXPLAIN ANALYZE:** Put before any query. Shows execution plan — Seq Scan vs Index Scan.

## PAGINATION — COVERED W6 D6

**Offset pagination:** Client sends `page` and `limit`. Server calculates `skip = (page-1) * limit`. DB applies `OFFSET skip LIMIT limit`. Simple to implement. Works well for small/medium datasets. Allows jumping to any page directly.

**Problem at scale:** DB scans and discards all skipped rows internally. Page 1000 with limit 10 = DB processes 10,010 rows to return 10. Also unstable when rows are inserted frequently — rows can shift between pages causing duplicates or gaps.

**Cursor pagination:** Instead of skip, use a marker — last seen `id` or timestamp. Query becomes `WHERE id > last_id LIMIT 10`. DB uses index to jump directly. No scanning. Consistent performance at any depth.

**Tradeoff:** Cursor can't jump to arbitrary pages — forward only. Good for infinite scroll, logs, real-time feeds. Offset is fine for small datasets or when direct page jumping is needed (e.g. jumping to a faulty device quickly).

**IoT rule:** Device list → offset fine. Second-by-second sensor readings at scale → cursor.

## ALEMBIC — COVERED W6 D4

**What it is:** Migration tool for SQLAlchemy. Tracks schema changes as versioned scripts. Unlike `create_all`, Alembic can add/remove columns on existing tables.

**Setup (once per project):**
- `alembic init migrations` → creates folder + alembic.ini + env.py
- `alembic.ini` → set `sqlalchemy.url = postgresql://user:pass@localhost:5432/db` (localhost, not Docker service name)
- `migrations/env.py` → set `target_metadata = Base.metadata` (import Base from models)

**Commands:**
- `alembic revision --autogenerate -m "message"` → detects model changes, generates script
- `alembic upgrade head` → applies all pending migrations
- `alembic downgrade -1` → undo last migration
- `alembic current` → show current migration state
- `alembic history` → show all migrations

**`alembic_version` table:** Created automatically. Tracks which migrations are applied. Never touch manually.

**Key rule:** Alembic runs outside Docker → needs `localhost:5432`. FastAPI runs inside Docker → needs `db:5432`. Two different URLs, both correct.

## BACKTRACKING — COVERED W6 D1 + W6 D3 + W6 D5 + W6 D7

**Subsets (LC #78):** Record `curr` BEFORE the loop (captures empty set). Loop from `index`. push → recurse(`i+1`) → pop.

**Permutations (LC #46):** Record only when `curr.size() == nums.size()`. Loop always from 0. `visited[]` tracks used elements. visited[i]=true → push → recurse → pop → visited[i]=false.

**Combination Sum (LC #39):** Loop from `ind`. Reuse same element → recurse with `i` not `i+1`. Pruning: sum > target → return. sum == target → push → save → return. Pass `sum + candidates[i]` inline to avoid undo. Always push → recurse → pop.

**Letter Combinations (LC #17):** `ind` = which digit you're at. Loop through all letters of `phn[digits[ind]]`. Recurse with `ind+1` (next digit). Base case: `curr.size() == digits.size()`. Map key must be `char` not `int` — `digits[ind]` is a char.

**Word Search (LC #79):** DFS backtracking on grid. Check `board[r][c] == word[ind]` before going deeper. Check `ind == word.size() - 1` immediately after match — return true if last char. Mark visited before recursing, unmark after. Bounds + visited check at top. Loop all cells in exist() — word can start anywhere.

**N-Queens (LC #51):** Place one queen per row top to bottom. Track cols, diag1 (row-col), diag2 (row+col) in unordered_sets. Safety check: `cols.count(c) || diag1.count(row-c) || diag2.count(row+c)` → continue. Place → insert all 3 sets → recurse(row+1) → remove → erase all 3 sets. Base case: row == n → push board to result. Board = `vector<string>(n, string(n, '.'))`.

**Palindrome Partitioning (LC #131):** `ind` = current position in string. Loop `i` from `ind` to `s.size()-1`. Substring = `s.substr(ind, i-ind+1)`. If palindrome → push → recurse(`i+1`) → pop. Base case: `ind == s.size()` → save result → return. Palindrome check: compare `s[i]` and `s[size-i-1]` in a loop.

**Sudoku Solver (LC #37):** 3 sets — `rows[9]`, `cols[9]`, `boxes[9]`. Box index = `(row/3)*3 + col/3`. Pre-fill sets from existing board before recursing. Traverse cell by cell: if `col==9` → next row. If cell filled → skip. If cell empty → try 1-9, check all 3 sets, place, recurse, undo if fails. Return `bool` — `true` propagates solution up and stops all further attempts. Base case: `row==9` → return true.

**Key differences — don't mix these up:**
- Subsets = i+1, record every node
- Permutations = visited[], loop from 0, record only at leaf
- Combination Sum = i (reuse), pass sum inline, prune on sum > target
- Letter Combinations = ind fixed per level, loop letters, ind+1 to recurse
- Word Search = grid DFS, mark/unmark cell, match char at each step
- N-Queens = row by row, 3 sets for constraints, place/erase
- Palindrome Partitioning = ind as cursor, substr(ind, i-ind+1), palindrome check before recurse
- Sudoku = cell by cell, 3 sets pre-filled, bool return to propagate solution

**JWT:** create_access_token(data) encodes `sub` + `exp` into token. verify_token(token) decodes and returns username. Protected route uses Depends(oauth2_scheme) to extract token. Schemes param needs a list.

**bcrypt:** CryptContext(schemes=["bcrypt"], deprecated="auto"). hash() hashes plain password. verify() takes plain + stored hash — bcrypt extracts salt internally, never hashes twice and compares directly. Always pin bcrypt==4.0.1.

**SQLAlchemy flow:** database.py creates engine from DATABASE_URL, Base, SessionLocal, get_db(). models.py imports Base from database.py. main.py imports both — avoid circular imports by not importing model inside database.py. Order at startup: create_tables() → routes run → get_db() yields session → add → commit → refresh.

**Pagination mental model:** skip = (page-1) * limit. Chain .offset(skip).limit(limit) on any query. Optional filter: build query first, apply .filter() only if param is not None, then chain offset + limit.

**relationship + back_populates:** Links two models. `device.readings` gives list of all DeviceReading objects for that device. `reading.device` gives the Device object for that reading. back_populates value must match the attribute name on the other side exactly.

**Normalisation:** 1NF = no repeating column groups. 2NF = no partial dependencies on composite key. 3NF = no transitive dependencies between non-key columns. Your schema already follows all three.

**Docker mental model:** Dockerfile → `docker build` → Image → `docker run` → Container. Alpine = 5MB base, uses `apk` not `apt`. RUN executes at build time, CMD executes at run time. Volumes = persistent storage that survives container restarts.

**nginx role:** Sits in front of the app on port 80. Forwards requests to `web:8000` via proxy_pass. Always `web:8000` not `localhost:8000` — Docker Compose services talk by service name, not localhost.

**Docker volume paths (fixed by image — never changes):** Postgres data = `/var/lib/postgresql/data`. nginx config = `/etc/nginx/conf.d/default.conf`.

**Tree recursion formula:** base case (nullptr) → go left → go right → combine → return. Always `root->left` not `left`.

**Graph patterns:** Multi-source BFS = seed all starting nodes at once. Mark visited when pushing to queue, not when popping. Clone Graph = set `visited[node] = clone` BEFORE the neighbor loop (prevents infinite loop on cycles). Topo sort DFS = 3 states (0/1/2), push to result post-order, reverse at end.

**Binary search:** `lo <= hi`, `mid = lo + (hi-lo)/2`, `lo = mid+1` / `hi = mid-1`. Rotated array: check which half is sorted first, then decide which side target is on.

**SQL rules:** Single `=` for comparison, not `==`. No quotes around integers. WHERE = before grouping. HAVING = after grouping. Every non-aggregate SELECT column must be in GROUP BY. LEFT JOIN anchor goes after FROM. Postgres is strict — exact table and column names required.

**.env rules:** No quotes. No spaces around `=`. No Python code. Plain text only.

**N-Queens mental model:** One queen per row. 3 sets track conflicts: cols, diag1 (row-col), diag2 (row+col). Safety = not in any of the 3 sets. Board = vector of strings. Place = `board[row][c] = 'Q'`. Remove = `board[row][c] = '.'`.

**Word Search mental model:** DFS from every cell. Mark cell before recursing, unmark after. Check last character match before recursing deeper — `ind == word.size() - 1`. Bounds + visited + char check at top of DFS.

**TCP/IP layers:** Application (app data) → Transport (TCP/UDP, ports) → Internet (IP addresses, routing) → Network Access (physical, ethernet/WiFi). Remember: All Turtles In Nebraska.

**TCP server flow:** socket() → bind() → listen() → accept() → recv/send(). socket = create. bind = claim IP+port. listen = tell OS to queue connections. accept = block until client connects, returns client_fd. recv/send = read/write data on that fd.

**DNS full flow:** Browser cache → OS cache → Recursive resolver (ISP) → Root nameserver (who handles .com?) → TLD nameserver (who handles google.com?) → Authoritative nameserver (returns actual IP). TTL = how long each hop caches the result. Short TTL = fast propagation, more traffic. Long TTL = fewer lookups, stale risk.

**Sudoku solver mental model:** 3 sets pre-filled from existing board. Box index = `(row/3)*3 + col/3`. Traverse cell by cell. Empty cell → try 1-9 → check rows/cols/boxes → place → recurse → undo if stuck. Return bool. Base case row==9 = solved.

**Palindrome partitioning mental model:** `ind` is a cursor — everything before it is already partitioned. Loop `i` from `ind` — try every possible end for current piece. `substr(ind, i-ind+1)` extracts the piece. If palindrome → push → recurse(i+1) → pop. Base case ind==s.size() = all characters consumed, save result.

## THINGS I STRUGGLED WITH

*(new entries from W6 D7 appended)*

- **What:** DNS — skipped recursive resolver and root nameserver step. **Why:** jumped straight from OS cache to TLD. **Fix:** full order is browser → OS → recursive resolver → root → TLD → authoritative. Resolver is the workhorse. Root tells you who handles the TLD. TLD tells you who handles the domain. Authoritative returns the actual IP.
- **What:** LC #39 — fall-through after `res.push_back(curr)`. **Why:** forgot `return` after saving. **Fix:** after saving a result in backtracking, always return immediately.
- **What:** LC #39 — modifying `sum` in the loop instead of passing inline. **Why:** tried to track sum as a variable and undo it. **Fix:** pass `sum + candidates[i]` directly into the recursive call. No undo needed.
- **What:** LC #131 — `substr(i, ind)` instead of `substr(ind, i-ind+1)`. **Why:** confused start and length arguments. **Fix:** `substr(start, length)`. Start = `ind`. Length = `i - ind + 1`.
- **What:** LC #131 — loop from 0 instead of `ind`. **Why:** thought of it as scanning the full string each time. **Fix:** `ind` is the cursor. Loop always starts from `ind`, never from 0.
- **What:** LC #37 — used `||` instead of `&&` in constraint check. **Why:** read it as "if any set doesn't have it." **Fix:** number is valid only if ALL three sets don't have it — must be `&&`.
- **What:** LC #37 — undo placed in else branch instead of after recursion. **Why:** thought undo happens when number is invalid. **Fix:** undo happens after recursion fails — not when the number is skipped.
- **What:** LC #37 — `i + '1'` instead of `i + '0'`. **Why:** off by one in char arithmetic. **Fix:** to convert int `i` (1-9) to char: `'0' + i`.
- **What:** LC #37 — box index `(trow/3)*3 + tcols` missing `/3`. **Why:** forgot to divide column by 3. **Fix:** box index = `(row/3)*3 + col/3`. Both row and col divided by 3.
