- **Why:** the conceptual gap behind it
- **Fix:** the mental model or rule to say before writing next time

Example:
- What: used `j` instead of `j+1` in substr
- Why: confused `substr(start, length)` with `substr(start, end)`

"What" without "Why" is just a log. "Why" without "Fix" doesn't change behavior.

## BACKTRACKING — COVERED W6 D1

See `08_repeat/lc-problems/lc-78-subsets.cpp` and `lc-46-permutations.cpp`

**Subsets (LC #78):**
- Record `curr` at every node — BEFORE the loop (this is how empty set is captured)
- Loop from `index` to `n`
- push → recurse(`i+1`) → pop

**Permutations (LC #46):**
- Record only when `curr.size() == nums.size()`
- Loop always from 0
- `visited[]` tracks used elements
- `visited[i]=true` → push → recurse → pop → `visited[i]=false`

**Key difference:** Subsets moves forward only (`i+1`), records every node. Permutations loops from 0 always, uses visited array, records only at leaf.

## THINGS I STRUGGLED WITH

Format: What | Why | Fix

- **What:** confused recursion with backtracking. **Why:** didn't realise backtracking = pick + recurse + unpick — the undo step is mandatory. **Fix:** before any backtracking problem, say "pick → recurse → unpick" out loud.
- **What:** used `ind+1` instead of `i+1` in recursive call. **Why:** mixed up the fixed start index with the loop variable. **Fix:** `ind` is the function parameter, `i` is the loop counter — recurse with `i+1` always.
- **What:** recorded inside loop instead of before loop in subsets. **Why:** missed that subsets must include the empty set — recording before any picking is how that happens. **Fix:** in subsets, first line of the function is `result.push_back(curr)`, before the loop opens.
- **What:** tried resetting ind=0 instead of using visited array for permutations. **Why:** didn't understand permutations need all elements available at each step, not just forward ones. **Fix:** permutations = visited[], subsets = i+1. These two rules don't mix.
- **What:** `j` vs `j+1` in LC #139 bottom-up substr. **Why:** confused `substr(start, length)` — length is `j-i`, not `j`. **Fix:** write `s.substr(i, j-i)` and say "j minus i is the length."
- **What:** missing `-r` in `pip install -r requirements.txt`. **Why:** habit of writing `pip install <package>` — forgot `-r` means read from file. **Fix:** Dockerfile pip line is always `RUN pip install -r requirements.txt`. The `-r` is non-optional.
- **What:** `ss -tulnp` not remembered. **Why:** new command, first encounter Apr 24. **Fix:** `ss` = socket statistics. Flags = tcp, udp, listening, numeric, process. First cold attempt W6 D2.
