## BINARY SEARCH TEMPLATE — MEMORIZE

```cpp
int lo = 0, hi = n - 1;
while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;
    if (nums[mid] == target) return mid;
    else if (nums[mid] < target) lo = mid + 1;
    else hi = mid - 1;
}
return -1;

// Rotated array rules:
// 1. nums[mid] >= nums[l] → left half is sorted (use >=)
// 2. target >= nums[l] && target <= nums[mid] → search left (use >= and <=)
// 3. Otherwise search right
// 4. Always && not & for logical AND
```
