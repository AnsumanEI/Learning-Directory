## STRUGGLES LOG

- **What:** `pg_isready` healthcheck failing with wrong database name. **Why:** without `-d` flag, Postgres uses system username as database name. **Fix:** always add `-d ${POSTGRES_DB}` to healthcheck command.
- **What:** Redis connection refused inside Docker container. **Why:** `localhost` inside a container refers to the container itself. **Fix:** always use Docker service name for container-to-container communication.
- **What:** Docker container name not known. **Why:** assumed container names. **Fix:** container names follow pattern `<project>-<service>-<instance>`. Always run `docker ps` first.
- **What:** throughput variable used uninitialized in scheduler. **Why:** declared but not set to 0.0. **Fix:** always initialise doubles to 0.0 at declaration.
- **What:** Operator struct defined after function that uses it. **Why:** C++ reads top to bottom. **Fix:** always define structs and classes before the functions that use them.
- **What:** Code Runner using Windows paths in Git Bash. **Why:** `$dir` returns backslash paths. **Fix:** add `"code-runner.fileDirectoryAsCwd": true` to settings.json.
- **What:** `=` used instead of `==` in return check for networkDelayTime. **Why:** assignment vs comparison confusion. **Fix:** always double-check condition expressions — single `=` is always assignment in C++.
- **What:** chmod octal for `r--` written as 2 instead of 4. **Why:** r=4, w=2, x=1 not memorised. **Fix:** say "r is 4, w is 2, x is 1" before writing any octal. r--=4, -w-=2, --x=1.
- **What:** Bellman-Ford inner/outer loop merged into one. **Why:** misunderstood that V-1 repetitions and edge iteration are separate concerns. **Fix:** outer loop = repeat V-1 times. Inner loop = go through every edge. Always two separate loops.
