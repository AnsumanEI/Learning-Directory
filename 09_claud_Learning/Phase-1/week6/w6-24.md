## BACKTRACKING — COVERED W6 D1

**Subsets (LC #78):** Record `curr` BEFORE the loop (captures empty set). Loop from `index`. push → recurse(`i+1`) → pop.

**Permutations (LC #46):** Record only when `curr.size() == nums.size()`. Loop always from 0. `visited[]` tracks used elements. visited[i]=true → push → recurse → pop → visited[i]=false.

**Key difference:** Subsets = i+1 (forward only), record every node. Permutations = visited[], loop from 0, record only at leaf. These two rules do not mix.

## REFERENCE — KEY CONCEPTS (no code, just rules)

**JWT:** create_access_token(data) encodes `sub` + `exp` into token. verify_token(token) decodes and returns username. Protected route uses Depends(oauth2_scheme) to extract token. Schemes param needs a list.

**SQLAlchemy flow:** database.py creates engine from DATABASE_URL, Base, SessionLocal, get_db(). models.py imports Base from database.py. main.py imports both — avoid circular imports by not importing model inside database.py. Order at startup: create_tables() → routes run → get_db() yields session → add → commit → refresh.

**Docker mental model:** Dockerfile → `docker build` → Image → `docker run` → Container. Alpine = 5MB base, uses `apk` not `apt`. RUN executes at build time, CMD executes at run time. Volumes = persistent storage that survives container restarts.

**nginx role:** Sits in front of the app on port 80. Forwards requests to `web:8000` via proxy_pass. Service name (`web`) works because Docker Compose puts services on the same internal network.

**Tree recursion formula:** base case (nullptr) → go left → go right → combine → return. Always `root->left` not `left`.

**Graph patterns:** Multi-source BFS = seed all starting nodes at once. Mark visited when pushing to queue, not when popping. Clone Graph = set `visited[node] = clone` BEFORE the neighbor loop (prevents infinite loop on cycles). Topo sort DFS = 3 states (0/1/2), push to result post-order, reverse at end.

**Binary search:** `lo <= hi`, `mid = lo + (hi-lo)/2`, `lo = mid+1` / `hi = mid-1`. Rotated array: check which half is sorted first, then decide which side target is on.

## THINGS I STRUGGLED WITH

Format: What | Why | Fix

- **What:** confused recursion with backtracking. **Why:** didn't realise backtracking = pick + recurse + unpick — undo step is mandatory. **Fix:** say "pick → recurse → unpick" before any backtracking problem.
- **What:** `ind+1` instead of `i+1` in recursive call. **Why:** mixed up fixed start index with loop variable. **Fix:** `ind` = function param, `i` = loop counter — recurse with `i+1` always.
- **What:** recorded inside loop instead of before loop in subsets. **Why:** missed that empty set must be captured — recording before any picking does this. **Fix:** first line of subsets function is `result.push_back(curr)`, before loop opens.
- **What:** tried resetting ind=0 instead of using visited array for permutations. **Why:** didn't understand permutations need all elements at each step. **Fix:** permutations = visited[], subsets = i+1. These two rules don't mix.
- **What:** `substr(i, j)` instead of `substr(i, j-i)` in LC #139 bottom-up. **Why:** confused `substr(start, length)` — length is `j-i`, not `j`. **Fix:** say "j minus i is the length" before writing.
- **What:** missing `-r` in `pip install -r requirements.txt` in Dockerfile. **Why:** habit of `pip install <package>`. **Fix:** Dockerfile pip line always has `-r`. Non-optional.
- **What:** `ss -tulnp` not remembered. **Why:** new command, first encounter Apr 24. **Fix:** ss = socket statistics. Flags = tcp, udp, listening, numeric, process.
- **What:** `left` vs `root->left` in trees. **Why:** shorthand habit. **Fix:** always write `root->left`, never bare `left`.
- **What:** binary search — `>` instead of `>=`, `&` instead of `&&`. **Why:** syntax slip. **Fix:** condition is `lo <= hi`, operator is `&&`.
- **What:** LC #20 — closing bracket direction in map wrong. **Why:** stored open→close then checked backwards. **Fix:** map stores close→open. Check `map[s[i]] == stack.top()`.
- **What:** SQLite — `VALUE` not `VALUES`. **Why:** typo. **Fix:** always `INSERT INTO ... VALUES (...)`.
- **What:** TCP server — `iss >> value` ran twice. **Why:** extracted inside condition and again in body. **Fix:** extract once, store, then use.
- **What:** 401 vs 403 confused. **Why:** both are auth-related. **Fix:** 401 = not authenticated (who are you?), 403 = not authorized (I know who you are, but no).
- **What:** `HTTPExtension`, `basemodel` wrong casing. **Why:** guessing import names. **Fix:** `HTTPException`, `BaseModel` — capitals matter.
- **What:** graph bounds — swapped rows/cols. **Why:** r = y axis, c = x axis — easy to mix. **Fix:** `r < rows && c < cols` — r pairs with rows, c pairs with cols.
- **What:** `return;` instead of `return nullptr` in Node* function. **Why:** forgot return type was pointer. **Fix:** non-void function always returns a value.
- **What:** `visited[node] = clone` placed after loop instead of before. **Why:** didn't understand placement prevents infinite loops on cycles. **Fix:** mark visited BEFORE iterating neighbors.
- **What:** `details` instead of `detail` in HTTPException. **Why:** typo. **Fix:** FastAPI uses `detail` (singular).
- **What:** JWT `Return` capital R. **Why:** Python is case-sensitive. **Fix:** always lowercase `return`.
- **What:** `and` instead of `or` in login condition. **Why:** logic confusion. **Fix:** wrong credentials = username wrong OR password wrong — not AND.
- **What:** docker tag — missed format. **Why:** not memorized. **Fix:** `docker tag <image> <username>/<repo>:<tag>` — three parts after `docker tag`.
- **What:** database.py ~30% cold retention. **Why:** first time writing ORM pattern cold. **Fix:** repeat — engine, Base, SessionLocal, get_db in that order.
