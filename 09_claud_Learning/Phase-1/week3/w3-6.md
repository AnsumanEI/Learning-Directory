## TREE FOUNDATIONS — COVERED APR 6 (do not re-explain unless asked)

### What a node is
- `TreeNode` struct has three things: `val`, `left`, `right`
- `left` and `right` are not values — they are **addresses** (pointers) to other nodes
- `NULL` means "no node exists in this direction"
- The `: val(x), left(nullptr)` constructor syntax = `this->val = x` — same thing

### Recursion on trees — the 5-step formula
```
1. Base case      → if (root == nullptr) return SOMETHING
2. Go left        → recurse on root->left
3. Go right       → recurse on root->right
4. Combine        → use left and right answers
5. Return         → send answer up
```

### LC #226 — Invert Binary Tree ✅
```cpp
TreeNode* invertTree(TreeNode* root) {
    if (root == nullptr) return nullptr;
    TreeNode* left = invertTree(root->left);
    TreeNode* right = invertTree(root->right);
    root->left = right;
    root->right = left;
    return root;
}
```
**Common mistake made:** wrote `invertTree(left)` instead of `invertTree(root->left)` — `left` variable doesn't exist yet at that point.

### LC #104 — Max Depth of Binary Tree ✅
```cpp
int maxDepth(TreeNode* root) {
    if (root == nullptr) return 0;
    int left = maxDepth(root->left);
    int right = maxDepth(root->right);
    return max(left, right) + 1;
}
```
**Key insight:** base case returns 0 not 1 — nullptr is not a node, counting it as 1 overcounts every level.
**Formula:** `max(left, right) + 1` — take the deeper side, add 1 for yourself.
