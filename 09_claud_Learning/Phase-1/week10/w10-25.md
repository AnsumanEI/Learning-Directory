- **What:** `pg_isready` healthcheck failing. **Why:** without `-d` flag, Postgres uses system username. **Fix:** always add `-d ${POSTGRES_DB}`.
- **What:** Redis connection refused inside Docker. **Why:** `localhost` = the container itself. **Fix:** always use Docker service name.
- **What:** Docker container name not known. **Why:** assumed container names. **Fix:** `docker ps` first, pattern is `<project>-<service>-<instance>`.
- **What:** throughput variable used uninitialized. **Why:** declared but not set to 0.0. **Fix:** always initialise doubles to 0.0 at declaration.
- **What:** Operator struct defined after function that uses it. **Why:** C++ reads top to bottom. **Fix:** always define structs before functions that use them.
- **What:** Code Runner using Windows paths in Git Bash. **Why:** `$dir` returns backslash paths. **Fix:** add `"code-runner.fileDirectoryAsCwd": true` to settings.json.
- **What:** `=` used instead of `==` in return check. **Why:** assignment vs comparison confusion. **Fix:** always double-check condition expressions.

- **What:** Bellman-Ford inner/outer loop merged. **Why:** V-1 repetitions and edge iteration are separate concerns. **Fix:** outer = repeat V-1 times, inner = every edge. Always two separate loops.
- **What:** `localhost` used inside Docker to connect to RabbitMQ. **Why:** localhost inside container = the container itself. **Fix:** always use service name.
- **What:** RabbitMQ port not mapped to host. **Why:** ports without host mapping are internal only. **Fix:** check `docker ps` PORTS column.
- **What:** `exc: Exception` added as route parameter. **Why:** confused function parameter scope with try/except variable. **Fix:** FastAPI injects parameters from request only.
- **What:** TLS cert check attributed to server instead of client. **Why:** confused who sends vs who verifies. **Fix:** server sends cert, client verifies. Ask "who benefits from verification?"

- **What:** Floyd-Warshall, LC #1334, LC #787 needed full teaching. **Why:** all-pairs shortest path is new territory. **Fix:** say three-loop structure before writing: k → i → j.
