## DOCKER — COVERED W4 D3 (Apr 12)

### Core concepts

- **Image** — blueprint/recipe. Read-only. Built from Dockerfile.
- **Container** — running instance of an image. Can have many containers from one image.
- **Dockerfile** — instructions to build an image.
- **Docker Hub** — like GitHub but for images. `docker pull` downloads from here.
- Flow: `Dockerfile → build → Image → run → Container`

### Dockerfile structure — FWCRC

```dockerfile
FROM python:3.11-slim        # base image — start from here
WORKDIR /app                 # working folder inside container
COPY . .                     # copy your files into container
RUN pip install -r requirements.txt   # install dependencies during build
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]  # run at startup
```

**RUN vs CMD:**

- `RUN` = runs while building the image (setup)
- `CMD` = runs when container starts (launch)
- Only ONE CMD allowed

**COPY . . explained:**

- First `.` = your laptop's current folder
- Second `.` = /app inside the container

**--host 0.0.0.0 explained:**

- Without it, server only listens to requests from inside the container
- 0.0.0.0 = listen to requests from anywhere — needed for Docker

### Docker commands

```bash
docker pull python:3.11-slim          # download image from Docker Hub
docker build -t fastapi-app .         # build image from Dockerfile in current folder
docker run -p 8000:8000 fastapi-app   # run container, map port 8000
docker ps                             # list running containers
docker ps -a                          # list all containers including stopped
docker stop <container_id>            # stop a running container
docker rm <container_id>              # remove a stopped container
docker images                         # list all images on your machine
```

**-p 8000:8000 explained:**

- Left 8000 = port on your laptop
- Right 8000 = port inside container
- Creates a tunnel — requests to laptop:8000 go into container:8000

### requirements.txt

```bash
source venv/bin/activate
pip freeze > requirements.txt         # auto-generate from your venv
```

Then in Dockerfile use `RUN pip install -r requirements.txt` instead of listing libraries manually.

### 3-step rule — always

```python
conn = sqlite3.connect("users.db")    # 1. connect
cursor = conn.cursor()
cursor.execute("...")                  # 2. execute
conn.commit()                         # 3. commit (writes only — not needed for SELECT)
conn.close()                          # close
```

### 4 SQL commands

| What         | Command                      |
| ------------ | ---------------------------- |
| Create table | `CREATE TABLE IF NOT EXISTS` |
| Insert row   | `INSERT INTO`                |
| Get all rows | `SELECT * FROM`              |
| Get one row  | `SELECT * FROM ... WHERE`    |

### ? placeholder rule

```python
cursor.execute("INSERT INTO users (name, role) VALUES (?, ?)", (user.name, user.role))
```

Always use ? for values — never write values directly in SQL string.

### Column types

- `INTEGER` — numbers
- `TEXT` — strings
- `REAL` — decimals

## TREE FOUNDATIONS — COVERED W3 D4 + W4 D1

### TreeNode struct

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
```

### Recursion on trees — 5-step formula

```
1. Base case      → if (root == nullptr) return SOMETHING
2. Go left        → recurse on root->left
3. Go right       → recurse on root->right
4. Combine        → use left and right answers
5. Return         → send answer up
```

### LC #226 — Invert Binary Tree ✅

```cpp
TreeNode* invertTree(TreeNode* root) {
    if (root == nullptr) return nullptr;
    TreeNode* left = invertTree(root->left);
    TreeNode* right = invertTree(root->right);
    root->left = right;
    root->right = left;
    return root;
}
```

### LC #104 — Max Depth recursive ✅

```cpp
int maxDepth(TreeNode* root) {
    if (root == nullptr) return 0;
    int left = maxDepth(root->left);
    int right = maxDepth(root->right);
    return max(left, right) + 1;
}
```

### LC #104 — Max Depth iterative BFS ✅

```cpp
int maxDepth(TreeNode* root) {
    if (root == nullptr) return 0;
    queue<TreeNode*> q;
    q.push(root);
    int depth = 0;
    while (!q.empty()) {
        int levelSize = q.size();
        for (int i = 0; i < levelSize; i++) {
            TreeNode* node = q.front();
            q.pop();
            if (node->left)  q.push(node->left);
            if (node->right) q.push(node->right);
        }
        depth++;
    }
    return depth;
}
```

### LC #100 — Same Tree recursive ✅

```cpp
bool isSameTree(TreeNode* p, TreeNode* q) {
    if (p == nullptr && q == nullptr) return true;
    else if (p == nullptr || q == nullptr) return false;
    else if (p->val != q->val) return false;
    bool left  = isSameTree(p->left,  q->left);
    bool right = isSameTree(p->right, q->right);
    return left && right;
}
```

### LC #100 — Same Tree iterative ✅ (NEW — W4 D3)

```cpp
bool isSameTree(TreeNode* p, TreeNode* q) {
    stack<pair<TreeNode*, TreeNode*>> st;
    st.push({p, q});
    while (!st.empty()) {
        pair<TreeNode*, TreeNode*> current = st.top();
        st.pop();
        TreeNode* node1 = current.first;
        TreeNode* node2 = current.second;
        if (node1 == nullptr && node2 == nullptr) continue;
        else if (node1 == nullptr || node2 == nullptr) return false;
        else if (node1->val != node2->val) return false;
        st.push({node1->left, node2->left});
        st.push({node1->right, node2->right});
    }
    return true;
}
```

### LC #572 — Subtree of Another Tree ✅

```cpp
bool isSubtree(TreeNode* root, TreeNode* subRoot) {
    if (root == nullptr) return false;
    if (root->val == subRoot->val) {
        if (isSameTree(root, subRoot)) return true;
    }
    bool left  = isSubtree(root->left,  subRoot);
    bool right = isSubtree(root->right, subRoot);
    return left || right;
}
```

**Complexity:** O(n×m)

### LC #200 — Number of Islands DFS ✅

```cpp
void dfs(vector<vector<char>>& grid, int x, int y) {
    int rows = grid.size();
    int cols = grid[0].size();
    if (x < 0 || x >= rows || y < 0 || y >= cols) return;
    if (grid[x][y] == '0') return;
    grid[x][y] = '0';
    dfs(grid, x+1, y);
    dfs(grid, x-1, y);
    dfs(grid, x, y+1);
    dfs(grid, x, y-1);
}
int numIslands(vector<vector<char>>& grid) {
    int count = 0;
    for (int x = 0; x < grid.size(); x++) {
        for (int y = 0; y < grid[0].size(); y++) {
            if (grid[x][y] == '1') {
                dfs(grid, x, y);
                count++;
            }
        }
    }
    return count;
}
```

### LC #200 — Number of Islands BFS ✅ (NEW — W4 D3)

```cpp
void bfs(vector<vector<char>>& grid, int x, int y) {
    int rows = grid.size();
    int cols = grid[0].size();
    queue<pair<int,int>> q;
    q.push({x, y});
    grid[x][y] = '0';
    while (!q.empty()) {
        auto [cx, cy] = q.front();
        q.pop();
        if (cx+1 < rows && grid[cx+1][cy] == '1') { grid[cx+1][cy] = '0'; q.push({cx+1, cy}); }
        if (cx-1 >= 0  && grid[cx-1][cy] == '1') { grid[cx-1][cy] = '0'; q.push({cx-1, cy}); }
        if (cy+1 < cols && grid[cx][cy+1] == '1') { grid[cx][cy+1] = '0'; q.push({cx, cy+1}); }
        if (cy-1 >= 0  && grid[cx][cy-1] == '1') { grid[cx][cy-1] = '0'; q.push({cx, cy-1}); }
    }
}
int numIslands(vector<vector<char>>& grid) {
    int count = 0;
    for (int x = 0; x < grid.size(); x++) {
        for (int y = 0; y < grid[0].size(); y++) {
            if (grid[x][y] == '1') {
                bfs(grid, x, y);
                count++;
            }
        }
    }
    return count;
}
```

**Key:** mark '0' immediately when pushing — prevents same cell added twice.

### LC #133 — Clone Graph ✅

```cpp
Node* dfs(Node* node, unordered_map<Node*, Node*>& visited) {
    if (node == nullptr) return nullptr;
    if (visited.count(node)) return visited[node];
    Node* clone = new Node(node->val);
    visited[node] = clone;
    for (Node* p : node->neighbors) {
        clone->neighbors.push_back(dfs(p, visited));
    }
    return clone;
}
Node* cloneGraph(Node* node) {
    unordered_map<Node*, Node*> visited;
    return dfs(node, visited);
}
```

**Key:** `visited[node] = clone` before the for loop — prevents infinite loop on cycles.

## HTTP/HTTPS + TLS — COVERED W3 D7 (Apr 9)

  |--------- 1. Client Hello ----------->|
  |<-------- 2. Server Hello + Cert -----|
  |  [client verifies cert with CA]      |
