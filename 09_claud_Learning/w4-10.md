## TREE FOUNDATIONS — COVERED W3 D4 + W4 D1

### TreeNode struct
```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
```

### Build tree with input
```cpp
void buildTree(TreeNode*& root) {
    int val;
    cin >> val;
    if (val == -1) return;
    root = new TreeNode(val);
    buildTree(root->left);
    buildTree(root->right);
}
```
**Key:** `*&` = reference to pointer. Without `&`, changes don't affect the real pointer.

### Inorder traversal
```cpp
void inorder(TreeNode* root) {
    if (root == nullptr) return;
    inorder(root->left);
    cout << root->val;
    inorder(root->right);
}
```

### Recursion on trees — 5-step formula
```
1. Base case      → if (root == nullptr) return SOMETHING
2. Go left        → recurse on root->left
3. Go right       → recurse on root->right
4. Combine        → use left and right answers
5. Return         → send answer up
```

### LC #226 — Invert Binary Tree ✅
```cpp
TreeNode* invertTree(TreeNode* root) {
    if (root == nullptr) return nullptr;
    TreeNode* left = invertTree(root->left);
    TreeNode* right = invertTree(root->right);
    root->left = right;
    root->right = left;
    return root;
}
```

### LC #104 — Max Depth recursive ✅
```cpp
int maxDepth(TreeNode* root) {
    if (root == nullptr) return 0;
    int left = maxDepth(root->left);
    int right = maxDepth(root->right);
    return max(left, right) + 1;
}
```

### LC #104 — Max Depth iterative BFS ✅
```cpp
int maxDepth(TreeNode* root) {
    if (root == nullptr) return 0;
    queue<TreeNode*> q;
    q.push(root);
    int depth = 0;
    while (!q.empty()) {
        int levelSize = q.size();
        for (int i = 0; i < levelSize; i++) {
            TreeNode* node = q.front();
            q.pop();
            if (node->left)  q.push(node->left);
            if (node->right) q.push(node->right);
        }
        depth++;
    }
    return depth;
}
```
**Key:** read `q.size()` before the for loop — captures exact level size. `depth++` outside for loop — increments only when full level done.

### LC #100 — Same Tree ✅
```cpp
bool isSameTree(TreeNode* p, TreeNode* q) {
    if (p == nullptr && q == nullptr) return true;
    else if (p == nullptr || q == nullptr) return false;
    else if (p->val != q->val) return false;
    bool left  = isSameTree(p->left,  q->left);
    bool right = isSameTree(p->right, q->right);
    return left && right;
}
```

### LC #572 — Subtree of Another Tree ✅
```cpp
bool isSubtree(TreeNode* root, TreeNode* subRoot) {
    if (root == nullptr) return false;
    if (root->val == subRoot->val) {
        if (isSameTree(root, subRoot)) return true;
    }
    bool left  = isSubtree(root->left,  subRoot);
    bool right = isSubtree(root->right, subRoot);
    return left || right;
}
```
**Complexity:** O(n×m) — isSubtree called n times, each isSameTree costs m.

## GRAPH FOUNDATIONS — COVERED W4 D1 (Apr 11)

### Graph node struct
```cpp
class Node {
public:
    int val;
    vector<Node*> neighbors;
    Node(int val) : val(val) {}
};
```

### Key differences from tree
- Tree: fixed left/right children, no cycles, always move downward
- Graph: any number of neighbors, cycles possible, need visited tracking

### Graph DFS with visited
```cpp
void dfs(Node* node, unordered_map<Node*, bool>& visited) {
    if (node == nullptr) return;
    if (visited[node]) return;
    visited[node] = true;
    cout << node->val << " ";
    for (Node* neighbor : node->neighbors) {
        dfs(neighbor, visited);
    }
}
```

### LC #200 — Number of Islands ✅
```cpp
void dfs(vector<vector<char>>& grid, int x, int y) {
    int rows = grid.size();
    int cols = grid[0].size();
    if (x < 0 || x >= rows || y < 0 || y >= cols) return;
    if (grid[x][y] == '0') return;
    grid[x][y] = '0';
    dfs(grid, x+1, y);
    dfs(grid, x-1, y);
    dfs(grid, x, y+1);
    dfs(grid, x, y-1);
}
int numIslands(vector<vector<char>>& grid) {
    int count = 0;
    int rows = grid.size();
    int cols = grid[0].size();
    for (int x = 0; x < rows; x++) {
        for (int y = 0; y < cols; y++) {
            if (grid[x][y] == '1') {
                dfs(grid, x, y);
                count++;
            }
        }
    }
    return count;
}
```
**Key:** mark `'0'` before recursing. Main loop finds islands, DFS sinks them.

### LC #133 — Clone Graph ✅
```cpp
Node* dfs(Node* node, unordered_map<Node*, Node*>& visited) {
    if (node == nullptr) return nullptr;
    if (visited.count(node)) return visited[node];
    Node* clone = new Node(node->val);
    visited[node] = clone;
    for (Node* p : node->neighbors) {
        clone->neighbors.push_back(dfs(p, visited));
    }
    return clone;
}
Node* cloneGraph(Node* node) {
    unordered_map<Node*, Node*> visited;
    return dfs(node, visited);
}
```
**Key:** `visited[node] = clone` before the for loop — prevents infinite loop on cycles. Map stores original → clone.

## AUTH FOUNDATIONS — COVERED W3 D5 (Apr 7)

### API Key auth
- Client sends `X-API-Key` header with every request
- Server checks against expected value
- Wrong or missing → 401

### JWT auth
- Client sends username + password to `POST /login`
- Server verifies, generates signed JWT using `python-jose`
- JWT structure: `header.payload.signature`
- `sub` = username, `exp` = expiry (30 min)
- Server calls `jwt.decode()` — no DB lookup needed
- Tampered or expired → `JWTError` → 401

### Key concepts
- 401 = not authenticated
- 403 = not authorized
- API keys: best for devices/services
- JWT: best for users/sessions — stateless, expiry built in

### POST /login — clean version
```python
class UserLogin(BaseModel):
    username: str
    password: str

@app.post("/login")
def login(user: UserLogin):
    if user.username != "admin" or user.password != "1234":
        raise HTTPException(status_code=401, detail="Invalid username or password")
    return {"message": "Login successful", "access_token": create_access_token(user.username)}
```

## HTTP/HTTPS + TLS — COVERED W3 D7 (Apr 9)

```
Client                                    Server
  |--------- 1. Client Hello ----------->|
  |<-------- 2. Server Hello + Cert -----|
  |  [client verifies cert with CA]      |
  |--------- 3. Session Key ------------>|
  |  [server decrypts with private key]  |
  |<======== 4. Encrypted HTTP data ====>|
```
- Asymmetric encryption — used once to exchange session key. Slow.
- Symmetric (AES) — used for all data after handshake. Fast.
- AWS IoT Core uses mTLS — both device AND server present certificates
