## BST — COVERED W7 D1

**BST property:** Every node in the entire left subtree must be less than root. Every node in the entire right subtree must be greater than root. Not just immediate children — entire subtree.

**Inorder traversal of valid BST always gives sorted order.** This is the key insight behind LC #98 and LC #230.

**Iterative inorder skeleton (used for both problems):**
```cpp
TreeNode* curr = root;
stack<TreeNode*> st;
while (curr != nullptr || !st.empty()) {
    while (curr != nullptr) {
        st.push(curr);
        curr = curr->left;
    }
    curr = st.top();
    st.pop();
    // VISIT curr here
    curr = curr->right;
}
```

**LC #98 — iterative:** Track `prev = nullptr`. After pop, check `prev != nullptr && prev->val >= curr->val` → return false. Update `prev = curr`. Return true after loop.

**LC #230 — iterative:** Track `count`. After pop, decrement count. If count == 0 → return curr->val.

**LC #98 — recursive:** Pass `prev` by reference (`TreeNode*&`). Go left → check prev vs root → update prev = root → go right. Return bool at every branch. Base case = nullptr → return true.

**Key C++ rule:** Always initialize pointers. `TreeNode* prev = nullptr` not `TreeNode* prev`. Uninitialized pointer = garbage value = silent wrong behavior.

**Stack mental model:** Stack holds pending ancestors. Inner while goes as far left as possible, pushing everything. Pop = visit that node. Then explore right subtree. Stack ensures you come back up to ancestors correctly.

## SQL — COVERED W6 D2
*(unchanged from previous handoff)*

**SELECT + FROM + WHERE:** SELECT picks columns. FROM picks table. WHERE filters rows before anything else.

**INNER JOIN:** Only matched rows from both tables. Unmatched rows on either side are excluded.

**LEFT JOIN:** All rows from left table. Unmatched rows on right show as NULL. Put the important table after FROM.

**RIGHT JOIN:** All rows from right table. Unmatched rows on left show as NULL. Rare — most people swap tables and use LEFT JOIN instead.

**GROUP BY:** Collapses rows with same value into one group. Every non-aggregate column in SELECT must appear in GROUP BY. Aggregates: COUNT, SUM, AVG, MAX, MIN.

**HAVING:** Filters groups after grouping. WHERE filters rows before grouping. That is the only difference.

**Subquery:** SELECT inside SELECT. Inner query runs first. Use IN (SELECT ...) to check if a value exists in a list.

**Index:** `CREATE INDEX idx_name ON table(column)`. Speeds up lookups. Seq Scan = no index = slow. Index Scan = index used = fast.

**EXPLAIN ANALYZE:** Put before any query. Shows execution plan — Seq Scan vs Index Scan.

## PAGINATION — COVERED W6 D6
*(unchanged)*

**Offset pagination:** Client sends `page` and `limit`. Server calculates `skip = (page-1) * limit`. DB applies `OFFSET skip LIMIT limit`. Simple to implement. Works well for small/medium datasets. Allows jumping to any page directly.

**Problem at scale:** DB scans and discards all skipped rows internally. Page 1000 with limit 10 = DB processes 10,010 rows to return 10. Also unstable when rows are inserted frequently — rows can shift between pages causing duplicates or gaps.

**Cursor pagination:** Instead of skip, use a marker — last seen `id` or timestamp. Query becomes `WHERE id > last_id LIMIT 10`. DB uses index to jump directly. No scanning. Consistent performance at any depth.

**Tradeoff:** Cursor can't jump to arbitrary pages — forward only. Good for infinite scroll, logs, real-time feeds. Offset is fine for small datasets or when direct page jumping is needed.

**IoT rule:** Device list → offset fine. Second-by-second sensor readings at scale → cursor.

## BACKTRACKING — COVERED W6 D1 + W6 D3 + W6 D5 + W6 D7
*(unchanged)*

**Subsets (LC #78):** Record `curr` BEFORE the loop. Loop from `index`. push → recurse(`i+1`) → pop.

**Permutations (LC #46):** Record only when `curr.size() == nums.size()`. Loop always from 0. `visited[]` tracks used elements.

**Combination Sum (LC #39):** Loop from `ind`. Reuse same element → recurse with `i` not `i+1`. Pass `sum + candidates[i]` inline. Always push → recurse → pop. After saving result, always return immediately.

**Letter Combinations (LC #17):** `ind` = which digit. Loop through letters of that digit. Recurse with `ind+1`. Map key must be `char`.

**Word Search (LC #79):** DFS on grid. Mark visited before recursing, unmark after. Check last char match before going deeper.

**N-Queens (LC #51):** One queen per row. 3 sets for constraints. Place/erase. Base case row == n.

**Palindrome Partitioning (LC #131):** `ind` is cursor. Loop `i` from `ind`. `substr(ind, i-ind+1)`. Base case ind == s.size().

**Sudoku Solver (LC #37):** 3 sets pre-filled. Box index = `(row/3)*3 + col/3`. Try 1-9, check sets, place, recurse, undo. Return bool. Base case row == 9.

**Key rule — i vs ind in Combination Sum:** Pass `i` to recurse, not `ind`. `i` = stay or go forward. `ind` = always restart from parent's position. Passing `ind` would allow duplicates like [2,3,2].

**JWT:** create_access_token(data) encodes `sub` + `exp` into token. verify_token(token) decodes and returns username. Protected route uses Depends(oauth2_scheme) to extract token. Schemes param needs a list.

**bcrypt:** CryptContext(schemes=["bcrypt"], deprecated="auto"). hash() hashes plain password. verify() takes plain + stored hash. Always pin bcrypt==4.0.1.

**SQLAlchemy flow:** database.py creates engine, Base, SessionLocal, get_db(). models.py imports Base. main.py imports both. Order: create_tables() → routes run → get_db() yields session → add → commit → refresh.

**Pagination mental model:** skip = (page-1) * limit. Chain .offset(skip).limit(limit). Optional filter: build query first, apply .filter() only if param is not None.

**relationship + back_populates:** Links two models. back_populates value must match attribute name on other side exactly.

**Normalisation:** 1NF = no repeating column groups. 2NF = no partial dependencies. 3NF = no transitive dependencies.

**Docker mental model:** Dockerfile → build → Image → run → Container. Alpine = 5MB, uses apk. RUN = build time. CMD = run time.

**nginx role:** Sits on port 80. Forwards to `web:8000`. Always service name, not localhost.

**Docker volume paths:** Postgres = `/var/lib/postgresql/data`. nginx = `/etc/nginx/conf.d/default.conf`.

**Tree recursion formula:** base case (nullptr) → go left → go right → combine → return.

**Graph patterns:** Multi-source BFS = seed all at once. Mark visited when pushing. Clone Graph = set visited before neighbor loop. Topo sort DFS = 3 states, push post-order, reverse.

**Binary search:** `lo <= hi`, `mid = lo + (hi-lo)/2`. Rotated array: check which half sorted first.

**SQL rules:** Single `=` for comparison. No quotes around integers. WHERE = before grouping. HAVING = after grouping.

**.env rules:** No quotes. No spaces around `=`. Plain text only.

**TCP/IP layers:** Application → Transport → Internet → Network Access. All Turtles In Nebraska.

**TCP server flow:** socket() → bind() → listen() → accept() → recv/send().

**DNS full flow:** Browser cache → OS cache → Recursive resolver → Root nameserver → TLD nameserver → Authoritative nameserver → IP. TTL controls caching duration.

**BST iterative inorder:** Push left until null. Pop = visit. Go right. Stack holds pending ancestors. Always initialize prev = nullptr.

## THINGS I STRUGGLED WITH

*(new entries from W7 D1 appended)*

- **What:** tcpdump — forgot `-w` flag to save to file, also `-v` and `-c`. **Why:** only memorised core flags, not utility flags. **Fix:** full command = `tcpdump -i eth0 -n -w capture.pcap port 80`. `-w` = write. `-v` = verbose. `-c N` = capture N packets then stop. `-r` = read saved file.
- **What:** LC #98 — `prev` declared but not initialized. **Why:** C++ doesn't auto-initialize pointers to nullptr. **Fix:** always write `TreeNode* prev = nullptr`. Never leave pointers uninitialized.
- **What:** LC #98 recursive — set `prev = root` before the check, so comparing node to itself. **Why:** confused update order. **Fix:** check first, then update. Go left → check prev vs root → prev = root → go right.
- **What:** LC #98 recursive — missing return values on recursive calls. **Why:** forgot bool must propagate up. **Fix:** `if (!checker(left)) return false`. Always return the result of recursive calls in bool functions.
