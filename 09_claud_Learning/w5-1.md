## DP — CLIMBING STAIRS (LC #70) — COVERED W5 D1

### Key insight
Climbing Stairs = Fibonacci in disguise.
`climb(n) = climb(n-1) + climb(n-2)`

### Version 1 — Recursive O(2^n)
```cpp
int climbStairs(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    return climbStairs(n-1) + climbStairs(n-2);
}
```

### Version 2 — Memoisation O(n) time, O(n) space
```cpp
int memory(int n, vector<int>& memo) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    if (memo[n] != -1) return memo[n];
    memo[n] = memory(n-1, memo) + memory(n-2, memo);
    return memo[n];
}

int climbStairs(int n) {
    vector<int> memo(n+1, -1);
    return memory(n, memo);
}
```

### Version 3 — Tabulation O(n) time, O(1) space ✅
```cpp
int memory(int n, int prev1, int prev2) {
    int current = 0;
    for (int i = 3; i <= n; i++) {
        current = prev1 + prev2;
        prev2 = prev1;
        prev1 = current;
    }
    return current;
}

int climbStairs(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    return memory(n, 2, 1);
}
```

### DP pattern to remember
| Approach | Time | Space |
|---|---|---|
| Recursive | O(2^n) | O(n) stack |
| Memoisation | O(n) | O(n) |
| Tabulation O(1) | O(n) | O(1) ✅ |

### Recurrence — teach this first
```
dp[i] = max(nums[i] + dp[i-2], dp[i-1])
```
At each house — rob it (take nums[i] + best from i-2) or skip it (take best from i-1).

### Base cases
- `dp[0] = nums[0]`
- `dp[1] = max(nums[0], nums[1])`

### O(1) space — two variables prev1, prev2. Loop from index 2.

## DFS TOPOLOGICAL SORT — COVERED W5 D1

### Full solution — built from scratch ✅
```cpp
class Solution {
public:
    bool dfs(int node, vector<int>& state, vector<vector<int>>& adj, vector<int>& result) {
        state[node] = 1;
        for (auto& p : adj[node]) {
            if (state[p] == 1) return false;
            else if (state[p] == 2) continue;
            else if (state[p] == 0) {
                if (!dfs(p, state, adj, result)) return false;
            }
        }
        state[node] = 2;
        result.push_back(node);
        return true;
    }

    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        vector<int> state(numCourses, 0);
        vector<vector<int>> adj(numCourses);
        vector<int> result;
        for (auto& p : prerequisites) {
            adj[p[1]].push_back(p[0]);
        }
        for (int i = 0; i < numCourses; i++) {
            if (state[i] == 0) {
                if (!dfs(i, state, adj, result)) return false;
            }
        }
        return true;
    }
};
```

### State meanings
| State | Meaning |
|---|---|
| 0 | Unvisited |
| 1 | Currently in recursion stack |
| 2 | Fully processed |

### Key rules
- Hit state=1 again → cycle → return false
- Hit state=2 → already safe → continue
- After all neighbors done → mark state=2, push to result
- Reverse result at end for topo order

```python
SECRET_KEY = "supersecretkey"
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 30

def create_access_token(data: dict):
    to_encode = data.copy()
    expire = datetime.utcnow() + timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES)
    to_encode.update({"exp": expire})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)

def verify_token(token: str):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        username = payload.get("sub")
        if username is None:
            raise HTTPException(status_code=401, detail="Invalid token")
        return username
    except JWTError:
        raise HTTPException(status_code=401, detail="Invalid token")

@app.get("/protected")
def protected_route(token: str):
    username = verify_token(token)
    return {"message": f"Hello, {username}! You have access to this protected route."}

@app.post("/login")
def login(username: str, password: str):
    if username == "admin" and password == "password":
        access_token = create_access_token(data={"sub": username})
        return {"access_token": access_token, "token_type": "bearer"}
    else:
        raise HTTPException(status_code=401, detail="Invalid username or password")
```

### TreeNode struct
```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
```

### Recursion on trees — 5-step formula
```
1. Base case      → if (root == nullptr) return SOMETHING
2. Go left        → recurse on root->left
3. Go right       → recurse on root->right
4. Combine        → use left and right answers
5. Return         → send answer up
```
