## THINGS I STRUGGLED WITH

- Stack problems: managing string + stack simultaneously is confusing first time
- `seen.count()` on a stack → compile error. Stacks don't have `.count()`. Only maps and sets do
- Pushed `s[0]` manually before loop → double-processed first character
- `match[')'] = ')'` typo — map value must be opposite bracket
- `pval.push.first(val)` → wrong. Push whole pair: `pval.push({val, min})`
- `pval.top().second()` → wrong. `second` is a field not a function: `pval.top().second`
- `pval.top.first()` → wrong. `top()` needs parentheses, `first` does not: `pval.top().first`
- `grep` needs dot: `grep -r "text" .`
- SSL errors on curl — use `-k` or `http://`
- `unordered_set` vs `unordered_map` confusion
- Forgot `return false` at end of Contains Duplicate
- Index typo: `values[nums[1]]` instead of `values[nums[i]]`
- Min-heap: pushed/extracted wrong field from pair
- LC #238: hardcoded loop variable `b` instead of `i`
- libcurl: missing `-lcurl` flag causes linker error
- libcurl: must use `http://` not `https://` for localhost
- libcurl: `curl_easy_reset()` needed between requests
- Deque: checking `win.back()` before `!win.empty()` → runtime crash
- Deque: used `if` instead of `while` when kicking from back
- SQLite: typos in SQL keywords — double check always
- SQLite: `VALUE` instead of `VALUES` in INSERT statement
- Cron: `* 12 * * *` ≠ midnight. Midnight = `0 0 * * *`. Minute comes first, then hour
