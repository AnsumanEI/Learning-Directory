---

This repository contains two complete projects built during a research internship at NIT Rourkela. Both run on the **ESP32 microcontroller** and were developed using the **Arduino IDE** and **Arduino C++**.

---

## 📦 Projects

### [`01_EWARN-IoT-Development-Kit/`](./01_EWARN-IoT-Development-Kit)
**33 experiments** covering every sensor and communication module on the EWARN IoT Development Board — from blinking an LED to sending SMS accident alerts over GSM and transmitting data over Free Space Optics (laser beams).

### [`02_Smart-Traffic-System/`](./02_Smart-Traffic-System)
A **4-intersection dynamic traffic light controller** with a real-time web dashboard, density-based signal prioritisation, IR sensors, Blynk cloud integration, and emergency vehicle detection. Built iteratively across 5 firmware versions.
